# EVENTFORCE – Event Management System Demo

## Run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use the sidebar to navigate between modules.

## Included
Dashboard, Events, Clients, Vendors, Venues, Event–Vendor Coordination, Approvals & Flows, Feedback, Reports.
CRUD actions (add/edit/delete), search, approval status controls, dashboard summaries, and print reports are functional.
Demo records are saved in the current browser using localStorage.

## Note
This is a front-end demo based on the supplied PDF. It does not include a server, shared database, login, or multi-user synchronization. The sample data is illustrative.
